# Kordovan sound kit (owned foley)

Record on a phone voice-memo app, 5–10 cm from the source, in a silent room. Record 3 takes of each. Export as WAV at 48 kHz.
Name each file exactly as below and commit it here. Book reference: §17.1.

| File | Sound |
|---|---|
| `snap_brass_01.wav` | **the sonic logo**: Mocha Mate brass snap, cleanest take. Goes on the horse mark in every end card |
| `snap_brass_02/03.wav` | alternates |
| `creak_flex.wav` | wallet bent open slowly |
| `card_slide_in.wav` | a card sliding into a slot |
| `cash_fold.wav` | notes folded in |
| `zip_jacket_up.wav` / `zip_jacket_down.wav` | jacket zip, full length |
| `stitch_pull.wav` | thread pulled tight |
| `burnish_rub.wav` | edge burnishing |
| `buckle_belt.wav` | belt buckle fastened |
| `leather_drop_on_wood.wav` | wallet dropped 10 cm onto wood |
| `room_tone_workshop.wav` | 30 s of workshop ambience, nobody talking |

External sounds don't go here. Put them in the project that uses them, with a `CREDITS.md` line for each.
