# Kordovan Team Rail (Chrome / Edge / Brave extension, free)
Pins the agent team with pixel avatars to the right edge of claude.ai. Hover = what they do; click = starts your message with their name ("Omar, ").
Install: unzip Kordovan_Team_Rail.zip → chrome://extensions → Developer mode ON → Load unpacked → pick the unzipped folder.
Update the roster: edit TEAM in rail.js (+ icons/<seat>.png, rendered from HQ avatars), re-zip, click Reload on the extension.
