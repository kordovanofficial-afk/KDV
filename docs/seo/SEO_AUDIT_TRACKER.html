✅ What's already working

  • ~96% of products have custom meta titles + descriptions (a titles pass was clearly done) — format Product | Kordovan Pakistan.
  • Every sampled product has image alt text, lazy-loading, and width/height on cards (good for Core Web Vitals / CLS).
  • Collection pages carry CollectionPage + ItemList JSON-LD; theme <head> has canonical, Open Graph, favicon, mobile-first responsive.
  • ~55% of products already have a review rating metafield (4.6–5.0).
  • Clean, keyword-friendly URL structure on most products (except the "copy-of" ones — see below).

🔴 The gaps that are costing you

  • No Product schema on the PDP → no price/stars/stock rich results in Google. Biggest single technical miss.
  • No Organization, BreadcrumbList, or FAQPage schema anywhere.
  • PDP enrichment metafields empty on 100% of products — custom.subtitle, custom.benefits, custom.material, custom.fits. The new PDP renders fallbacks until these are filled.
  • Meta descriptions are templated/generic — same "Buy the X… free shipping, lifetime warranty" pattern → weak keyword differentiation.
  • Alt text is inconsistent — many are filename-style ("// Black - Kordovan") not descriptive; full galleries not yet alt-tagged; images aren't the branded 5-shot set yet.
  • Internal codes in public titles — "TP The…", "DT Crushable…" — and "copy-of-…" handles on duplicated products (bad URLs + optics).
  • Messy product types & tags — inconsistent casing, empty types, typos ("Kordovan Leathe"). Tags drive the kdv- smart collections, so this ripples.
  • Reviews incomplete — rating exists on ~half, but reviews.rating_count + custom.reviews (text) needed for the stars + review block to render and for review rich snippets.
  • Blog / content cluster essentially empty — no informational content = missing top-funnel + AI-citation surface.
  • Off-site foundations unconfirmed — Search Console, Bing, GA4, Merchant Center, Google Business Profile.
  • Junk/thin pages likely indexable — order-confirmation pages, empty "11 11 sale", "KODO promotion". Should be noindexed.
