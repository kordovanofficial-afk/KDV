Phase 0Prep

Do today · ~30–60 min · zero risk

0.1 — Keep the domain alive

  1. Log in to the TMD client area (the panel from your screenshots).
  2. Go to All products & services → Domain Names → .com (kordovanleather.com) → Manage domain name.
  3. It renews in ~1 month: either renew it now or make sure auto-renew is ON for the DOMAIN. (We are only killing the hosting, never the domain.)

0.2 — Archive all old mail in Thunderbird (this IS the mail migration)

You already read these mailboxes in Thunderbird, so it holds a synced copy of everything. We turn that into a permanent offline archive — then nothing on the old server matters anymore.

  1. Open Thunderbird. In the left sidebar, scroll to the bottom to find Local Folders.
  2. Right-click Local Folders → New Folder… → name it Archive-admin. Repeat to create one per account: Archive-asadj, Archive-umair, Archive-contact, Archive-corporate, Archive-sales, Archive-marketing, Archive-social, Archive-daraz.
  3. For each account in the sidebar: click its Inbox, click any message, press Ctrl+A (select all), then right-click → Copy To → Local Folders → Archive-[name]. Wait for the status bar at the bottom to finish before moving on.
  4. Repeat step 3 for that account's Sent folder (and any custom folders you've made). Junk/Trash can be skipped.
  5. Spot-check: open each Archive-* folder and confirm the message counts look right (oldest mail visible at the bottom).
  6. Back up the whole Thunderbird profile: menu ☰ → Help → Troubleshooting Information → under "Profile Folder" click Open Folder → close Thunderbird completely → copy that entire folder to a USB drive or external disk.
Why this matters Zoho's free plan can't import from the old server, and the old server eventually dies with the hosting. After this step, your complete mail history lives on your own PC (plus the USB backup) forever — searchable in Thunderbird any time.

0.3 — Catch-all mailbox

Phase 1Zoho Mail — account, domain & users

~45 min + waiting for verification · zero risk · mail keeps flowing to TMD throughout

1.1 — Create the free account

  1. Go to zoho.com/mail → click Pricing.
  2. Scroll to the very bottom of the pricing page — below all the paid plans there is a small "Forever Free Plan" section (they hide it on purpose). Click Sign up now / Get started under it. It must say: 5 users, 5GB per user, one domain, webmail only.
  3. Register using admin@kordovanleather.com as the contact email (it still works on TMD right now) + your phone number. Verify the OTP they send.
  4. When asked, choose "Sign up with a domain I already own" → enter kordovanleather.com → organisation name: Kordovan.
Careful If at any point Zoho pushes you into a "trial of Zoho Workplace / Mail Premium", look for the skip link or "continue with free plan". You never need to enter a card.

1.2 — Prove you own the domain (TXT record at TMD)

  1. Zoho's setup wizard now shows a verification screen. Choose the TXT method. It shows a value like zoho-verification=zb12345678.zmverify.zoho.com. Keep this tab open.
  2. New tab → TMD client area → Manage web hosting → Login to cPanel.
  3. In cPanel find the Domains section → Zone Editor → next to kordovanleather.com click Manage.
  4. Click + Add Record → type TXT. Fields: Name = kordovanleather.com. (or just @ if it offers that), TTL = leave default, Record = paste the full zoho-verification=… value → Save.
  5. Back in the Zoho tab, click Verify. If it fails, wait 15–60 minutes and try again (DNS needs time to propagate). Retry until green.

1.3 — Create the 5 mailboxes

  1. Your signup account automatically becomes admin@kordovanleather.com — the Super Admin. That's seat 1. ✓
  2. Open the Admin Console: mailadmin.zoho.com → Users → Add User (or the wizard's "Add Users" step).
  3. Create each user — name, email prefix, and a strong unique password:
    · asadj@kordovanleather.com
    · umair@kordovanleather.com
    · contact@kordovanleather.com
    · corporate@kordovanleather.com
  4. Write the 5 passwords down somewhere safe (or a password manager). Each person changes theirs on first login.
  5. Recommended: turn on 2-factor authentication at least for admin@ (Admin Console → Security, or accounts.zoho.com → MFA).

1.4 — Create the 4 aliases

  1. Admin Console → Users → click admin → open its Mail settings / Email aliases panel → Add alias → sales@kordovanleather.com → save. Add daraz@kordovanleather.com the same way.
  2. Click asadj → add aliases marketing@kordovanleather.com and social@kordovanleather.com.
  3. That's all 9 addresses: 5 mailboxes + 4 aliases. Do not add a catch-all anywhere — unknown addresses should bounce (kills the spam).
Stop sign inside the Zoho wizard The wizard's next steps are "MX records / SPF / DKIM". Do NOT add MX records at TMD, and do not expect verification to pass yet. We add those records in Cloudflare in Phase 2, and they go live in Phase 3. It is completely fine to leave the Zoho wizard "incomplete" at this stage — mail keeps arriving at TMD/Thunderbird as usual. One thing you SHOULD do now: in the Zoho Admin Console go to Domains → kordovanleather.com → DKIM / Email configuration → generate the DKIM key (selector zmail is the default) and copy the TXT name and value into a notes file — you'll paste it in Phase 2.5.

Phase 2Cloudflare — build the new DNS (prepare only, switch later)

~40 min · zero risk — nothing changes until Phase 3

2.1 — Add the site

  1. Create a free account at dash.cloudflare.com/sign-up (use admin@kordovanleather.com).
  2. Click Add a domain → enter kordovanleather.com → Continue.
  3. Plan selection: scroll to the bottom → choose Free — $0 → Continue.
  4. Cloudflare auto-scans and imports your existing DNS records, then shows the record list. Don't trust the scan blindly — next step.

2.2 — Cross-check every record against cPanel (the important 10 minutes)

  1. Second tab: TMD cPanel → Zone Editor → Manage (same place as Phase 1.2). This shows the REAL current records.
  2. Compare line by line with Cloudflare's imported list. Anything cPanel has that Cloudflare missed → add it in Cloudflare (Add record), copying the values exactly.
  3. The records that keep the STORE alive — these must exist and match cPanel exactly:
    · A record, name @ (or kordovanleather.com) → the Shopify IP cPanel shows (typically 23.227.38.x)
    · CNAME www → shops.myshopify.com (or exactly what cPanel shows)
    · CNAME account → exactly what cPanel shows
  4. You can IGNORE / skip copying: records pointing at the TMD box itself — mail.kordovanleather.com, ftp, cpanel, webmail, webdisk, autodiscover, autoconfig, _domainkey entries from TMD, and the old MX records. They all die with the hosting.

2.3 — Grey-cloud the Shopify records

  1. In Cloudflare's DNS list, each A/CNAME record has a Proxy status cloud icon. Orange = proxied, grey = DNS only.
  2. Click Edit on the apex A record, the www CNAME and the account CNAME → set each to DNS only (grey cloud) → Save. Shopify manages its own SSL; proxying can break the padlock/checkout.

2.4 — Remove old mail records from the Cloudflare list

  1. Delete any imported MX records (they point to the TMD server).
  2. Delete any imported TXT record that starts with v=spf1 and mentions the TMD server (e.g. contains a mx or an IP). A domain may only have ONE SPF record and we're adding Zoho's next. Keep unrelated TXT records (e.g. google-site-verification, the zoho-verification one from Phase 1).

2.5 — Add the Zoho mail records

All via Add record. Use exactly the hostnames Zoho's setup page shows you (these are the standard ones):

2.6 — Get the nameserver pair (but don't switch yet)

  1. Click Continue / Done in Cloudflare. It shows the two nameservers assigned to you, like ana.ns.cloudflare.com and rick.ns.cloudflare.com (yours will differ).
  2. Write both down exactly. Cloudflare will now show the site as "Pending nameserver update" — correct, that's Phase 3.
Optional but smart Before Phase 3, screenshot your full Cloudflare DNS record list and send it to me — I'll cross-check it in one minute. If you'd rather run solo, the checklist above is complete.

Phase 3The switch — nameservers at TMD

5 min of clicking + a few hours of propagation · do it late night PKT
  1. Pick a quiet time (e.g. after 11 PM PKT). The site will NOT go down — this is just cautious scheduling.
  2. TMD client area → All products & services → Domain Names → Manage domain name → find Nameservers (sometimes under "Settings" or "DNS management").
  3. It currently lists TMD's nameservers. Choose "Use custom nameservers", delete the TMD entries, and enter the two Cloudflare nameservers from Phase 2.6. Save.
  4. Wait. Cloudflare emails you (and its dashboard banner turns to "Active") when it takes over — usually 15 min to a few hours, worst case 24h.
  5. What happens in the meantime: the website keeps serving from the identical Shopify records (visitors notice nothing). New email starts arriving in Zoho instead of TMD as resolvers pick up the new MX. During the overlap a stray message may still land at TMD — you'll sweep those in Phase 7.
  6. Once Cloudflare says Active: go back to the Zoho Admin Console → Domains → kordovanleather.com and let it verify MX / SPF / DKIM — each should turn green now.

Phase 4Shopify — verify nothing changed

5 min · read-only checks, change nothing
  1. Shopify admin → Settings → Domains: kordovanleather.com and www should both show Connected with no red warnings. (If a warning appears, see Fix-it below — it means a DNS record didn't match cPanel's values.)
  2. Shopify admin → Settings → Notifications: the sender email is admin@kordovanleather.com — leave it. If Shopify shows a banner offering to "authenticate your sender domain" by adding DNS records (CNAMEs), you may add exactly what it lists in Cloudflare — it improves deliverability of order-confirmation emails. Optional, any time.
  3. Open the live store in a private/incognito window: homepage, a product page, add to cart, proceed to checkout page (no need to order). Padlock everywhere.

Phase 5Phones & daily use

10 min per person
  1. Everyone installs the Zoho Mail app (Play Store / App Store) and logs in with their own address: admin@, asadj@, umair@ (+ whoever owns contact@ / corporate@ adds those accounts in the same app — the app supports multiple accounts).
  2. On desktop, daily mail is now mail.zoho.com in the browser. Bookmark it.
  3. Thunderbird stays installed purely as the ARCHIVE of pre-migration mail (the Archive-* local folders). The old TMD accounts in it will error once the hosting dies — that's expected; the Local Folders keep working forever.
  4. Replying as an alias: in Zoho compose, click the From dropdown — admin can send as sales@ / daraz@, asadj as marketing@ / social@.
