🐎 KORDOVAN — Jackets Shot Sheet

How to use this

One card per jacket, five shots each, and every prompt is complete on its own — the model, the framing rule, the palette and the protect-list are written into all 150 of them. You never need to scroll back up to this box. Read it once, then work from the copy buttons.

Per shot: open your image tool → attach the jacket's real Shopify photo → hit Copy prompt → paste → generate → save with the filename shown under the shot → tick the box.

The two rules this sheet exists to enforce

  • One man, one woman, across the whole range. Every men's jacket is worn by the same specified model; every women's jacket by the same woman. The full description is baked into each prompt, so the men's grid reads as one shoot and the women's as another.
  • No half crops. Ever. Every prompt states the whole garment must be in frame — collar, both cuffs, full hem — and explicitly forbids torso-only and waist-up crops. The on-body and lifestyle shots are full-length.

If a generated face comes out inconsistent between jackets, add this one line to the end of the prompt: "Frame the model from the chin down so the face is out of shot." Do it for every jacket or none — half and half is what breaks a grid.

What each shot is for

  • Shot 1 · Hero — the PDP main image and the collection card. Ghost mannequin on cream. If your upload has a person in it, the prompt removes them.
  • Shot 2 · On-body — scale and fit. Full-length, locked model, plain setting.
  • Shot 3 · Open — lining, inner pocket, inside of the collar. This is the trust shot; it is the one that answers "is it real leather inside too".
  • Shot 4 · Macro — different for every single jacket. The quilting on the Nightfall, the fur join on the Urban Rider, the wax pooling on the Durham, the rubbed-through elbow on the Allaric Alley.
  • Shot 5 · Lifestyle — the ad and social image. Every jacket gets its own scene, none repeated, so the grid never twins.

Honest note on how these were written. The product photos could not be opened from the session that built this sheet — the network proxy refuses Shopify's CDN. Style, colour and the protect-lists come from each product's title, handle and image alt text, which name the details explicitly. That is why every prompt is built around "keep the uploaded photo 100% identical": the garment always comes from your real photo, and the protect-list only tells the generator what not to smooth away. If a protect-list gets a detail wrong for a particular jacket, fix that one line in tools/jacket-shotsheet/jackets.py and re-run the builder.
