SEO & AI-Visibility Architecture

The complete playbook to make Kordovan the leather brand that ranks first on Google and gets recommended by ChatGPT, Gemini, Perplexity & Google AI Overviews — engineered for both discoverability and conversion. Built on the storefront we've already shipped (every page has the metafield + schema hooks this plan needs).

00Goals & Guardrails

Three outcomes, in priority order: (1) rank top-3 for commercial leather terms in Pakistan; (2) become the cited/recommended answer in AI engines for "best leather goods Pakistan"; (3) convert that traffic with depth + trust on every product.

Always do

  • One clear primary keyword per page; unique title + meta on every URL.
  • Write for the human first, then make it machine-extractable (headings, Q&A, specs).
  • Match on-page H1 intent to the meta title (cuts Google rewrites ~76% → ~20%).
  • Keep facts true & consistent everywhere (NAP, materials, warranty) — entities win in AI.
  • Self-author reviews that are genuine (real customers, real words), never fabricated volume.

Never do

  • Keyword-stuff titles, alt text, or descriptions (reads spammy to Google & LLMs).
  • Duplicate descriptions across products (the #1 leather-store SEO failure).
  • Fake review counts / star ratings you can't stand behind (rich-result penalty risk).
  • Block AI crawlers if you want AI recommendations (see §04).
  • Let filtered/search URLs get indexed as thin duplicate pages (canonical + noindex).

04AI Visibility — GEO / AEO

AI engines now handle ~12–18% of informational queries (up from <2% a year ago) and AI Overviews appear on 30–40% of Google searches. AI-referred visitors convert dramatically higher. Goal: be the cited source when someone asks an AI "best leather wallet in Pakistan / how to care for leather / Kordovan vs X".

How each engine picks sources

  • ChatGPT Search — powered by Bing. Favors comprehensive, well-sourced content with clear expertise; lifts bullet lists & FAQs verbatim. Action submit sitemap to Bing Webmaster Tools (most stores never do).
  • Perplexity — citation-first, real-time, weights freshness & sector authority; Reddit is ~47% of its sources. Action keep content fresh + earn genuine Reddit/forum mentions.
  • Google AI Overviews — uses normal ranking signals + synthesis. If you already rank, you tend to appear. FAQ/HowTo schema + short definitions help.

The GEO playbook (do these)

  1. Front-load answers. Start sections with a 1–2 sentence direct answer, then expand. ("Full-grain is the top layer of the hide; it's the most durable leather and ages into a patina.")
  2. Structure for extraction. Headings as questions, bullet specs, comparison tables, FAQ blocks. LLMs lift these directly.
  3. Strengthen entity authority. Consistent brand facts everywhere (Organization schema, About page, identical NAP), so engines confidently "know" Kordovan.
  4. Freshness cadence. Content updated within 30 days gets ~3.2× more AI citations — keep a monthly refresh on key guides.
  5. Earn third-party citations. Listicles, local press, "made in Pakistan" features, authentic Reddit/forum presence, Google reviews — AI trusts corroboration.
  6. Allow AI crawlers. Don't block GPTBot, OAI-SearchBot, PerplexityBot, Google-Extended in robots if you want to be recommended.

llms.txt? Optional. Google has said it's not required and the same foundations apply (useful, crawlable, well-structured, trustworthy content). We can ship a simple llms.txt listing key URLs later — low effort, low cost — but it's not a priority over the items above.

Measure it: literally ask ChatGPT, Gemini & Perplexity "best leather wallet brands in Pakistan" monthly and log whether Kordovan is named/cited. That's your AI rank tracker.

05Reviews & E-E-A-T

Reviews are simultaneously the biggest conversion lever (5+ reviews → ~270% better conversion) and a core trust/authority signal for Google & AI. We're authoring them ourselves — authentically — via metafields (no review app).

Self-authored review protocol

  • Base every review on real customer feedback (WhatsApp messages, order notes, DMs) — paraphrased, never invented.
  • Store per product: reviews.rating (e.g. 4.9), reviews.rating_count, and custom.reviews — one per line as Name|City|Text.
  • Keep ratings believable (4.6–4.9, not a wall of 5.0). Vary length, city, voice.
  • The PDP review block + star rating + Product aggregateRating all appear only when reviews.rating is set — so schema always matches visible content.

E-E-A-T signals to build

Experience/Expertise → founder story, "Our Craft" process, 22,000+ orders. Authoritativeness → consistent brand entity, press/citations. Trust → reviews, lifetime warranty, clear shipping/returns, real address & contact, secure checkout. We've built the surfaces; SEO pass fills them.

06Product Image System

Imagery is the #1 conversion factor (67% of shoppers) and a real organic channel (Google Images). Every product needs a consistent, warm, premium image set — same look across all SKUs so the catalogue feels like one brand.

The 5-shot order (every product)

  1. Flat-lay / front — clean catalog background (primary card + PDP hero).
  2. In-hand / on-body — scale & context.
  3. Open / inside — function (card slots, lining).
  4. Texture macro — the grain, stitching, edge (feel the leather).
  5. Lifestyle — styled on warm wood / linen / stone.

File naming (SEO)

Kebab-case, descriptive, keyword-led — before upload:

kordovan-full-grain-bifold-wallet-cognac-front.jpg
kordovan-full-grain-bifold-wallet-cognac-inside.jpg
kordovan-leather-messenger-bag-brown-lifestyle.jpg

Alt-text formula

Describe the image truthfully, keyword-aware, ≤100 chars (screen readers cut at 125, Google weights first 100). Each image gets a unique alt:

[Colour] [material] [product type], [view/context]
"Cognac full-grain leather bifold wallet, front view"
"Brown leather messenger bag worn on shoulder, lifestyle"
"Close-up of hand-stitched edge on tan leather wallet"

Image do

  • Keep backgrounds warm & identical across the catalog.
  • True-to-life leather colour (buyers must trust the cognac/brown).
  • Consistent angle for shot 1 on every SKU.
  • Compress before/after upload; keep it fast.

Image don't

  • Clinical pure-white #FFFFFF clinical bg (kills the warm brand feel) — unless a marketplace demands it.
  • Cool/blue white balance, heavy filters, fake HDR.
  • Mismatched product vs label (name must match the item shown).
  • Tiny/blurry images or inconsistent crops.

08Technical SEO

  • Sitemaps — Shopify auto-generates /sitemap.xml. Submit to Google Search Console AND Bing Webmaster Tools (Bing powers ChatGPT).
  • Canonicals — ensure filtered/sorted collection URLs (?filter…, ?sort_by…) canonical to the clean collection URL. Don't let them index as duplicates.
  • Noindex thin pages — internal /search results, cart, account, policy duplicates. Index only money + content pages.
  • Core Web Vitals — compressed WebP, lazy-loading (done), few apps, no render-blocking. Target LCP <2.5s, INP <200ms, CLS <0.1.
  • Mobile-first — already responsive; Google indexes mobile.
  • robots.txt — customize via robots.txt.liquid only to allow AI bots; keep checkout/cart disallowed.
  • Redirects — 301 any old/legacy-theme URLs & out-of-stock discontinued products to the parent collection (never leave 404s).
  • One H1 per page, logical H2/H3; descriptive internal links (not "click here").

12Per-Product Checklist

Repeat for every active product (bestsellers first). Everything maps to fields the theme already reads.

  • Meta title ≤60 — [Product] — [Material] Leather [Type] | Kordovan
  • Meta description ≤160 — benefit + material + feature + trust + CTA
  • Handle — clean, keyword, no numeric ID
  • Body description — unique, benefit-first; Features + Dimensions retained
  • custom.subtitle — material + type + benefit (shows under H1)
  • custom.benefits — 3 lines, one benefit each (buy-box bullets)
  • custom.material — e.g. "Full-Grain Cow Leather" (eyebrow + facts)
  • custom.fits — capacity, value|label per line (+ fits_title/fits_text)
  • 5 images — edited to §06 spec, named per convention, unique alt text each
  • reviews.rating + reviews.rating_count + custom.reviews (Name|City|Text)
  • Product type + tags — correct (drives kdv- collections + filters)
  • Internal links — related products in same collection; link from a guide

Once these are filled, the PDP automatically lights up the subtitle, benefit bullets, capacity panel, reviews block + star rating and Product schema — no code changes needed. The whole template is already wired to these fields.
