# Clarity decision (Founder asked Nov 28; Alex lens inline)
Data: Data Export API, last 3 days (about 2,174 sessions: 1,816 mobile, 315 PC, 43 tablet). Aggregates only (no recordings, no error text). Raw JSON in `data/`.

## What it shows
- Mobile = 84% of traffic. Average scroll depth 29% mobile (PC 39%): most mobile visitors never reach reviews, size guide or warranty.
- Quick-backs (click in, bounce straight back): 21.8% of mobile sessions; wallets collection page 33%, homepage 25%, jackets collection 25%. People are opening products and leaving.
- Script errors: 7.8% of mobile sessions; wallets collection 9.8% (19 errors on 61 sessions). Something on mobile is breaking. Error text is not in the API.
- Dead clicks (taps that do nothing): PC 20.6% of sessions, mobile 9.7%; homepage 92 dead clicks on 123 sessions, wallets collection 20% of sessions. (The homepage fake-reviews strip was hidden Nov 27; re-measure.)
- Rage clicks low (0.2% mobile). Excessive scroll 0.
- Sources: Google 737 sessions (22.8% quick-back), direct 685 (most engaged, 72s active), Facebook 646 (scroll 28%, 30s active, 15% quick-back), Meta 181, ChatGPT 41 (scroll 33%).
- Caveat: 3 days, includes Blessed Friday traffic; directional, not proof.

## Decision (conclusive)
1. Clarity CONFIRMS the CRO plan already approved (Nov 27); it adds NO new project. Keep it installed (free, light, no recordings watched).
2. Clarity's job from now = BEFORE/AFTER measurement of the CRO waves, not browsing: pull baseline Dec 3 (before Wave 0), then Dec 7 (3 days after the Dec 4 deploy) and Dec 11 (after Wave 1). Targets: mobile quick-back 22% -> under 17%; wallets collection quick-back 33% -> under 25%; script errors 7.8% -> under 2%; homepage dead clicks halved; mobile scroll depth 29% -> 40%.
3. Two items move UP in Wave 0 because of this data: (a) find and fix the mobile script error (needs the error name: Founder opens Clarity > Dashboard > Errors/Script errors and screenshots the top 3, 2 minutes); (b) wallets collection cards (quick-back 33%, errors 9.8%).
4. Do NOT enable Brand Agent / Agents JS (unchanged), no recordings review, no extra pulls beyond the 3 dated ones (API limit 10/day).
5. Revert rule unchanged: any CRO change whose Shopify collection/PDP conversion drops >15% relative over 14 days is reverted.
