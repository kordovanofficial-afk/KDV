# Kordovan HQ: anime character prompts (Nov 7 2026)

Make **2 images per character**: **WORK** (what they look like while working) and **IDLE** (what they do when free).
That is 16 images in total. HQ swaps between the two automatically by status and adds motion on top: breathing,
swaying, typing bob and small effects.

## Rules for every image (copy this STYLE block in front of each prompt)
```
STYLE: high-quality modern anime illustration, polished cel shading, clean confident lineart, soft cinematic
lighting, detailed expressive face and eyes, realistic adult proportions (not chibi, not cartoon), full body
head to shoes, centered, standing or seated as described, plain flat solid background color #241C16 with nothing
else, no text, no logo, no watermark, portrait 2:3, 1024x1536. Character design consistent across images.
```
**Save them as PNG and upload to Shopify → Content → Files with exactly these names:**
`hq-<seat>-work.png` and `hq-<seat>-idle.png` (the seat names are below).

Tip: make the WORK image first, then for IDLE give the tool the WORK image as a reference ("same character") so the
face and clothes stay identical.
